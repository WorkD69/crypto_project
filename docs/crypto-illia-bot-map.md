# Карта адаптера образовательного Telegram-бота

Публичная техническая редакция наблюдений от 18.10.2026. Username/peer привязки, ответы авторизованного диалога, приватные ссылки, точные названия кнопок и снимки интерфейса остаются локально.

## Структура и проверенная граница

Бот рассматривается как самостоятельный источник, отдельно от канала. Навигация включает корневую клавиатуру, разделы обучения и психологии, карточки материала и внешние ресурсы. В локальной проверке наблюдались 13 учебных ссылок. Прочитан один выбранный материал; архив остальных страниц не загружался. Покупки, подписки, Mini App и поддержка не запускались.

## Модель происхождения

Для выбранного материала сохраняется цепочка «проверенный источник → раздел → подраздел → материал → версия → правило». Нужны наблюдаемый идентификатор, исходное время либо `null`, момент импорта, хеш содержимого и путь меню. У правила хранятся короткое доказательство, условия применимости, ограничения и неопределённость. Реальные записи и цитаты не включены в Git.

| Содержимое | Технический путь | Граница |
| --- | --- | --- |
| Текст или подпись | `normalize_message` → `CollectorStore` → событие | Явный импорт конкретного разрешённого материала |
| Изображение | Локальное медиа → Qwen → проверка результата | Не доказано для авторского материала этим учебным циклом |
| Видео | Локальный разрешённый файл → ffmpeg/Whisper → временные сегменты | Тикеры и числа требуют проверки |
| Внешний урок | Ограниченное чтение выбранной страницы | Доступность не равна праву перепубликации |
| Итог | Hermes → проверка доказательств → черновик/журнал | Автоматическая публикация не включена |

## Ограничения

Редакции меню и повторная навигация должны сохранять версии и не создавать дубли. Нельзя автоматически нажимать неизвестные кнопки или переходить по произвольному URL. Для доступа используются только отдельные локальные профили; сессии не передаются Hermes и не публикуются. Результат одного ручного импорта не подтверждает круглосуточный сбор.
