# Ограниченное сравнение русского Whisper — 18.10.2026

Публичная редакция исторического эксперимента. Исходное аудио, транскрипты, хеши файлов и личное содержимое в репозиторий не включены.

Один разрешённый 45-секундный фрагмент, две последовательные транскрипции на RTX 3070 Laptop 8 GB: CUDA, `int8_float16`, beam 3, ru, temperature 0. Каждая модель запускалась в отдельном процессе. Hermes не запрашивал Whisper для выбранной карточки; это отдельная проверка готовности.

| Модель | Загрузка со скачиванием | Транскрипция | Наблюдаемый максимум памяти GPU |
| --- | ---: | ---: | ---: |
| large-v3-turbo | 84,06 с | 4,02 с | 1241 MiB |
| medium | 76,91 с | 9,06 с | 1241 MiB |

Это по одному прогону, без оценки вариативности. Память измерялась `nvidia-smi` раз в секунду и не является гарантированным пиком аллокатора модели. После завершения процессов наблюдалось 45 MiB. Ollama/Qwen в сравнении не участвовала.

Turbo быстрее примерно в 2,25 раза на этом фрагменте. Проверенного речевого эталона нет, поэтому WER/CER и точность терминов/чисел не вычислялись. Обе модели требуют проверки торговой терминологии. Совпадение двух распознаваний не является независимой проверкой речи автора. Автоматическое извлечение торговых уровней не аттестовано; глобальная модель не менялась.

Использовался отдельный уже установленный системный Python 3.12 с faster-whisper 1.2.1, CTranslate2 4.8.2, cuBLAS 12.9.2.10 и cuDNN 9.26.0.51. Этот эксперимент не устанавливал пакеты, драйверы или службы. Модельные веса хранятся только в игнорируемом `artifacts/models/`.

Исходный worker сохранён в `scripts/whisper_compare.py`; при переносе изменён только способ определения корня проекта и игнорируемого каталога результатов. Он рассчитан на существующий разрешённый локальный `artifacts/mvp_02_03/video_probe/audio_16khz.wav`, Windows и отдельные NVIDIA Python-пакеты. Обычные тесты его не запускают. Исторический одноразовый сценарий восстановления Hermes сохранён как неисполняемый шаблон `scripts/examples/resume-reviewed.py.example`, без реального session ID и пути к данным. Для действующего проекта повторять его нельзя: это материал для ручного аудита, а не автоматический retry.
