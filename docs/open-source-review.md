# Open-source review

Состояние по официальным проектам и документации на 12 октября 2026 года. «VPS» означает лёгкий процесс на 1 vCPU/2 GiB RAM рядом с уже работающим Hermes; полная установка перечисленных аналитических стеков туда не проверялась.

| Проект | Состояние, лицензия, функции и зависимости | Вывод для MVP |
| --- | --- | --- |
| [Telethon](https://docs.telethon.dev/en/stable/) | 1.45.0 на PyPI; MIT; Python MTProto, история/события/медиа/кнопки; `pyaes`, `rsa`, SQLite-session. GitHub-репозиторий архивирован после переезда проекта, актуальная документация указывает на Codeberg. Импорт 1.45.0 на Python 3.12 проверен локально. | Подходит для отдельного малоресурсного collector на VPS **после** согласий и теста собственного аккаунта. Сессию изолировать от Hermes; аккуратно обрабатывать FloodWait и update gaps. |
| [Hydrogram](https://github.com/hydrogram/hydrogram) / [Pyrogram](https://github.com/pyrogram/pyrogram) | Hydrogram — активный LGPL-3.0 форк для MTProto. Оригинальный Pyrogram архивирован в 2024 году, LGPL/GPL. | Резервный кандидат, если Telethon не пройдёт реальный тест; второй клиент сейчас добавит сложность и не решит вопрос лицензии контента. |
| [Telegraph API](https://telegra.ph/api) | Официальный HTTP JSON API, `getPage`, структурные Node/figure/figcaption; отдельной Python-библиотеки не требуется. | Прямой stdlib/httpx вызов на VPS подходит; проверять `ok`, лимит размера, ссылки и авторские права. |
| [bybit-exchange/pybit](https://github.com/bybit-exchange/pybit) | Официальный Python SDK, MIT, активные релизы; HTTP/WebSocket V5, включая публичные market endpoints. Сам SDK не устанавливался; прямой V5 GET реально испытан. | Для лёгкого чтения достаточно собственного тонкого GET-клиента; pybit подходит, если нужны WebSocket/reconnect. Не смешивать публичный и торговый клиент. |
| [tpwilo/smc](https://github.com/tpwilo/smc) / [joshyattridge/smart-money-concepts](https://github.com/joshyattridge/smart-money-concepts) | Реальные MIT-репозитории с FVG, swing, BOS/CHoCH, OB, liquidity на pandas/NumPy OHLC. У `tpwilo/smc` пометка BETA и очень малое сообщество; у joshyattridge открытые вопросы о look-ahead bias/streaming. | Только для офлайн-сравнения с авторскими правилами. Не принимать библиотечные определения за методику автора и не запускать как готовую сигнальную стратегию. Pandas/NumPy возможны на ноутбуке; для VPS учитывать память. |
| [tradingview/lightweight-charts](https://github.com/tradingview/lightweight-charts) | Активная JS/TS Canvas-библиотека, Apache-2.0 с NOTICE и обязательной атрибуцией TradingView по README; свечи, линии, плагины, live update. Нужен браузер для рендера. | Хороший выбор будущего интерактивного UI на ноутбуке/клиенте; сервер может отдавать данные. Для статической картинки в spike хватило Matplotlib. |
| [lightweight-charts-python](https://github.com/louisnw01/lightweight-charts-python) | MIT-обёртка; pandas + pywebview/GUI/браузер, live и аннотации. Зависит также от атрибуции базовой TradingView-библиотеки. | Удобно для локального прототипа; не ставить GUI/Chromium на маленький VPS. |
| [Freqtrade](https://github.com/freqtrade/freqtrade) | Активный GPL-3.0 бот/бэктест-стек; Python >=3.11 и тяжёлый набор ccxt, pandas, NumPy, TA-Lib, FastAPI и др. | Только будущий офлайн-бэктест в отдельной среде после формализации правил; не ставить на VPS и не использовать торговые возможности в этом проекте. |
| [TradingAgents](https://github.com/TauricResearch/TradingAgents) | Активный Apache-2.0 multi-agent framework, Python >=3.11, несколько LLM/provider и data API; по README требует настройку ключей либо локальной модели. | Использовать как архитектурный референс разделения ролей/аудита источников; полный стек дорог по вызовам и сложен для VPS. |

Источники для проверки: [Telethon releases](https://pypi.org/project/Telethon/), [Telethon sessions](https://docs.telethon.dev/en/stable/concepts/sessions.html), [Pyrogram archive](https://github.com/pyrogram/pyrogram), [Hydrogram license](https://github.com/hydrogram/hydrogram), [pybit license](https://github.com/bybit-exchange/pybit/blob/master/LICENSE), [SMC definitions](https://github.com/joshyattridge/smart-money-concepts/blob/master/README.md), [Lightweight Charts attribution](https://github.com/tradingview/lightweight-charts), [Freqtrade dependencies](https://github.com/freqtrade/freqtrade/blob/develop/pyproject.toml), [TradingAgents README](https://github.com/TauricResearch/TradingAgents).
