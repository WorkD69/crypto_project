# Ограничения одного рыночного эксперимента

Согласовано пользователем 18.10.2026 и применено только к процессам эксперимента.
Основной `config.yaml`, Gateway, боты, OAuth, расписания и личная память Hermes
не изменялись. Контрольная сумма действующего `config.yaml` проверяется отдельно.

В отдельном процессе штатного Hermes CLI перекрываются только:

```yaml
auxiliary:
  title_generation:
    enabled: false
agent:
  api_max_retries: 1
  auto_recovery_cycles: 0
```

В установленном коде `api_max_retries: 1` означает одну попытку основного
запроса; `auto_recovery_cycles: 0` отключает дополнительную лестницу
восстановления. Это не доказывает отсутствие повторов на транспортном уровне:
их нужно отдельно учитывать. Название сессии не требует обращения к модели.

Перекрытие действует только в процессе эксперимента. Используется небольшой
загрузчик штатного CLI, который читает действующие настройки, меняет эти поля
в памяти и считает обращения к модели, включая auxiliary. Файлы конфигурации
Hermes не перезаписываются. Максимум пять запросов Luna для одного события,
без автоматического повторного запуска после неизвестного исхода.

Нативные инструменты отключаются уже проверенным `--toolsets no_mcp`.
JSON-адаптер исполняет только разрешённые операции проекта; это не отдельный
Hermes и не новый сервис. Ошибки и исчерпание бюджета переводят событие в
`NEEDS_REVIEW`. Секреты и приватные материалы остаются в локальном runtime.
