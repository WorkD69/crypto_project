Подробности и ошибки — в [mvp-0.1-report.md](mvp-0.1-report.md). Саму Telegram-сессию Codex не получал и Hermes не передавал.

## Telegram

Официальные [Telegram API Terms](https://core.telegram.org/api/terms) и [Content Licensing and AI Scraping Terms](https://telegram.org/tos/content-licensing) запрещают scraping/indexing/aggregation данных платформы для разработки, проверки и применения AI/ML, если нет применимого узкого исключения с явным, информированным и продолжающимся согласием всех затронутых пользователей. Согласие на один чат/канал не переносится на другой. Условия правообладателя контента соблюдаются дополнительно. Наличие публичного канала или легальный вход аккаунтом само по себе не является лицензией на обучение модели, RAG, анализ уроков или публикацию производных материалов.

До сбора авторских материалов нужны: (1) подтверждение прав автора и всех релевантных участников/владельцев конкретного контента на выбранную обработку и хранение; (2) проверка применимости исключения Telegram именно к запланированному AI-workflow, включая облачную Luna; (3) срок, объём, отзыв согласия и удаление данных; (4) разрешение на производные посты/цитирование; (5) отдельно право на видео, речь, изображения и подписи. При сомнении требуется юридическая проверка до ingest.

**Текущий тест:** Telethon 1.45.0 установлен в изолированное `.venv`; реальный импорт `TelegramClient`, `events.NewMessage`, `events.Album`, `iter_messages`, `download_media` прошёл. Вход в аккаунт и чтение живых сообщений ожидают локального действия владельца; контент чужих каналов не собирался. [Документация Telethon](https://docs.telethon.dev/en/stable/modules/client.html) описывает `iter_messages` и `min_id`, [события](https://docs.telethon.dev/en/stable/modules/events.html) — NewMessage и Album. Альбом фактически состоит из отдельных сообщений с общим `grouped_id`; только один обработчик Album может быть недостаточен для абсолютной полноты при задержках. `message.buttons` можно прочитать без нажатия; взаимодействие с ботом в этом spike не выполнено.

Скрипт `scripts/telegram_own_source_probe.py` ограничен собственным источником, 20 последними сообщениями и максимум 120 сек наблюдения. Он не скачивает контент и не отправляет сообщений. Для реальной скорости, RAM, медиа, кнопок и live event нужны собственные тестовые сообщения/альбом/бот. [Telethon session documentation](https://docs.telethon.dev/en/stable/concepts/sessions.html) предупреждает, что `.session` содержит ключ авторизации. Поэтому она лежит вне Git и Hermes, и не печатается.

## Telegraph

Официальный [Telegraph API](https://telegra.ph/api) поддерживает публичный `getPage/<path>?return_content=true` без токена. Тестовая страница `https://telegra.ph/Likvidnost-poisk-tochek-vhoda-07-27-2` реально вернула HTTP 200 и `ok=true`; API вернул 35 верхнеуровневых узлов, 10 `figure`, 10 `img`, 10 `figcaption`, все десять пар image+caption находятся внутри соответствующих figure. Текст извлекается рекурсивно, порядок сохраняется порядком массива `content`. Тестовая несуществующая страница вернула HTTP 200, `ok=false`, `PAGE_NOT_FOUND`; одного HTTP-кода недостаточно. Техническая доступность не подтверждает право копировать урок в репозиторий или использовать его как AI-источник. В проект не записан полный текст, адреса изображений или их копии.

Для страницы, опубликованной через Telegraph, нужно выяснить правообладателя и условия использования отдельно; связь с Telegram может накладывать дополнительную проверку правил платформы, если контент получен из Telegram. Предпочтителен собственный или прямо разрешённый учебный материал.

## Bybit

Публичные рыночные данные V5 доступны без торгового ключа с Windows и VPS в испытании. Использованы только GET `/v5/market/time`, `/instruments-info`, `/kline`, `/funding/history`, `/open-interest`; `retCode` нужно проверять даже при HTTP 200. Регионального отказа в этом испытании не было. При появлении такого отказа не использовать VPN/прокси для обхода: остановить ingest и рассмотреть официально доступную региональную площадку или лицензированный источник данных.
