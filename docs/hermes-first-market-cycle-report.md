# Первый рыночный цикл Hermes — 18.10.2026

Публичная техническая редакция. Содержимое приватного канала, цитаты, исходные
идентификаторы/ссылки, изображения, точное время оригинала, ценовые области и
аналитический черновик остаются в игнорируемом локальном runtime. Полный отчёт
и доказательства находятся в `artifacts/market-cycle-20261018/`.

## Результат и честная граница

Выполнено одно историческое событие: выделенный Telegram Watcher → SQLite
event → решения действующего Hermes → Bybit V5 → числовая проверка Python →
размеченный PNG → аналитический черновик Hermes. Финальный статус события
`COMPLETED`, результат эксперимента `COMPLETED_WITH_OPERATOR_REVIEW`.

Это содержательный цикл с выбором инструментов Hermes, но **не полностью
автономный прогон**. Codex выбрал один пост из видимого хвоста, запустил
адресный Watcher и выполнил два проверенных восстановления. Рыночные операции
и их параметры выбрал Hermes; Python не подменял его торговым сценарием.
Новых публикаций и сделок не было, следующий этап не запускался.

## Источник и Watcher

Выделенный persistent-профиль подтвердил заголовок и ранее привязанный peer
разрешённого канала. Это проверка канала, отдельно от образовательного бота;
импорт из браузера Codex не использовался. После просмотра видимого хвоста
выбран один содержательный исторический пост с конкретным активом, числовым
порогом и двумя изображениями. Полная дата получена из штатной подсказки
Telegram Web при наведении на время.

Адресный проход сохранил один материал/одно событие и два изображения. История
целиком не выгружалась. `--message-id` теперь ограничивает сам сбор, а не только
перепроверку медиа, и не продвигает общий курсор источника. Поиск цели ограничен
`max_scrolls`, но отсутствие цели в первых двух viewport больше не считается
доказательством конца истории. UI readiness не доказывает полноту серверной
истории; `server_sync_confirmed=false` сохранено.

## Решения Hermes и исполнение

| Ход | Решение Hermes | Фактическое исполнение |
| --- | --- | --- |
| 1 | Историческая проверка выбранного актива на проверочном spot-рынке; 1H, 4H, 1D | `bybit_snapshot`: три публичных GET `/v5/market/kline` |
| 2 | Проверить исходный числовой порог и построить 1H-график | `check_price_level`, затем `render_chart` |
| 3 | Подготовить самостоятельное наблюдение с происхождением выводов | JSON разбора и русский черновик |

На каждом ходе Hermes видел событие, каталог и результаты уже выбранных
операций. Следующий запрос зависел от ответа модели. Параметры и причина
каждого решения сохранены локально. Походы в произвольные URL/файлы, shell,
торговые и публикационные операции отсутствуют в allowlist. Повторы одной
операции с другими пояснениями также блокируются.

Hermes отделил утверждение автора о ликвидности от наблюдаемого пересечения
порога на OHLC. Он указал неизвестную исходную биржу и таймфрейм, выбрал Bybit
как проверочный proxy, сохранил entry/SL/TP пустыми и не объявил подтверждённую
сделку. Связь с методикой ограничил исследовательской эвристикой проекта.
`read_method_card` доступен, но в этом прогоне модель его **не вызвала**:
новая проверка правил автора этим прогоном не доказана.

Авторские изображения Hermes решил не обрабатывать: для выбранной проверки
хватило текста. Поэтому путь «авторский график → Qwen → Bybit» ещё не доказан.
Whisper не вызывался, видео и модели не скачивались.

## Рыночные данные и график

Все три набора содержат по 199 закрытых свечей после отсечения незакрытой
свечи. Запрос `end` привязан к оригинальному времени. Python проверяет
хронологию, интервалы, конечность/положительность OHLC, соответствие рынка и
символа, отсутствие пропусков и устаревшего хвоста. Учитываются только свечи,
закрытые не позже cutoff. Это предотвращает использование последующих свечей;
исторические API-данные всё равно получены ретроспективно, а не записаны в
момент исходной публикации.

Операция `check_price_level` проверила число из текста по последним 30 закрытым
свечам. Прокол и закрытие выше порога наблюдаются на OHLC; реальные стопы и
достаточность быстроты возврата из этого не следуют. Общая количественная
эвристика прошлых/равных экстремумов — формализация проекта, не код автора и
не доказательство прибыльности.

PNG построен существующим Matplotlib renderer: выбранный рынок и таймфрейм,
UTC-ось, оригинальное время/cutoff, свечи, проверенный исходный порог и последняя
закрытая цена. Числа Qwen на график не переносились. Для текущего cutoff
`analysis` подпись явно отличается от исторического `publication`. В живом
прогоне Hermes запросил только историческую проверку; текущего сигнала нет.

## Сбои и восстановление без повторной Luna

1. Во втором ответе Hermes заменил NBSP обычными пробелами. Старая строгая
   проверка цитаты отклонила пакет **до** его исполнения; событие стало
   `NEEDS_REVIEW`. После проверки двух успешных raw streams Codex применил
   нормализацию только Unicode-пробелов и явно запустил `--resume-reviewed`.
   Старые модельные запросы не отправлялись заново. Восстановление отказывается
   повторять неизвестные inference и частично выполненные пакеты инструментов.
2. Финальный ответ содержал один лишний `}` после законченного JSON. Снова
   `NEEDS_REVIEW`, без автоматического retry. Codex проверил третий raw stream,
   счётчик обращений, результаты инструментов и валидатор финала, затем принял
   нормализованный ответ. Исходные байты сохранены. Новый parser фиксирует
   `REMOVED_ONE_SURPLUS_CLOSING_BRACE` и хеш исходного ответа; другой хвост,
   второй JSON-объект или ошибка нативного tool use отвергаются.

Смысл raw draft не переписывался при приёме. Отдельная локальная редакторская
копия уточняет формулировку о неизвестности результата автору и убирает
служебный путь. Это редактура Codex, а не дополнительный результат Hermes.

## Ограничение расходов и Ollama

Согласованные [временные настройки](hermes-market-runtime-proposal.md)
применены загрузчиком штатного CLI только в памяти отдельного процесса.
Preflight проверил отсутствие нативных инструментов и нулевой model count.
`--toolsets no_mcp` в установленной версии даёт предупреждение о неизвестном
наборе, но фактически пустой список; это проверяется, а не предполагается.

Обёртка HTTPX считает отправки к model endpoints, включая auxiliary, и до сети
блокирует второй запрос процесса либо модель, отличную от Luna. Для текущего
проверенного HTTPX-пути получено по одному `model_invocation` и `inference_audit`
на ход. Другой транспорт или обновление Hermes требуют нового preflight и
аудита: отсутствие ожидаемого счётчика останавливает цикл. Тело запросов,
заголовки и авторизации не включаются в ledger.

SQLite резервирует до пяти ходов рыночного эксперимента за UTC-день до запуска
модели. Reservation сохраняется при неизвестном исходе. Lease проверяется и
продлевается перед каждым модельным/инструментальным действием. Это отдельный
лимит данного адаптера; общей квотой универсального Hermes он не управляет.

| Измерение | Факт |
| --- | ---: |
| Luna model invocations, включая служебные | 3 |
| Title / summary / дополнительные повторы | 0 / 0 / 0 |
| Luna input / output tokens | 12 891 / 1 523 |
| Cache-read tokens | 0 |
| JSON-операции адаптера / HTTP GET Bybit | 3 / 3 |
| Qwen: собственный тестовый PNG / авторские изображения | 1 / 0 |
| Qwen input / output tokens | 2 070 / 229 |
| Qwen время собственного теста | 23,25 с |
| Whisper / Sol | 0 / 0 |

Стоимость в деньгах и доля общей квоты не установлены.

Перед проверкой процесс Ollama отсутствовал. Запуск установленной команды
поднял существующий сервер на loopback, API `/api/tags` подтвердил установленную
vision-модель. Переустановки/скачивания модели не было. В старом логе обнаружены
таймауты обнаружения GPU; точная причина отсутствия сервера во время прошлого
испытания не восстановлена. Сейчас CUDA/RTX 3070 определилась, собственный PNG
разобран в структурный JSON. Это доказывает работоспособность текущего вызова,
а не устраняет все возможные причины прежних зависаний.

## Проверки, приватность и оставшаяся ручная работа

На завершении кода: **94 теста прошли**, включая все 12 браузерных контрактов.
Проверяются итеративный выбор операций на синтетическом событии, запрет
повторной обработки завершённого события, неизвестный исход без retry,
сохраняемый бюджет, wire guard, process-only настройки, адресный сбор/дата,
NBSP/числа, валидация цен, график, безопасный разбор JSON и ошибки инструментов.
Использованы реальный Playwright на синтетическом DOM и отдельный живой прогон;
синтетические тесты не объявляются доказательством Telegram 24/7.

Дополнительно перед публикацией выполняются компиляция Python, разбор
PowerShell, `git diff --check`, проверка staged-файлов на секреты, приватные
идентификаторы/инвайты и runtime-медиа, сверка Git и контроль неизменности
конфигурации Hermes. В зависимостях Matplotlib/NumPy наблюдается
`DeprecationWarning`; тесты проходят, конфиги проверок не менялись.

Ручными остаются выбор одного материала, запуск адресного сбора/цикла,
проверенное восстановление после ошибки и редакторская проверка черновика.
Автоматические решения Hermes об инструментах и детерминированные расчёты
Python различаются в локальной трассировке. Дневник старых идей не изменялся,
фальшивой торговой записи нет. Постоянный мониторинг и расписание не включены.

Исходная ветка и `origin/main` после `fetch` совпадали с опубликованным
`a083a16a20d06e328583426fbc8501428245c9b3`; рабочее дерево было чистым.
Изменения подготовлены в `codex/hermes-market-cycle`, без переписывания истории.
