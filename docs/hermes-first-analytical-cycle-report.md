# Первый аналитический цикл Hermes — 18.10.2026

Публичная редакция: инвайты, peer/message ID, содержимое авторизованных Telegram-диалогов, исходные цитаты, session ID, хеши приватных данных и сведения учётных записей не публикуются. Полный исходный отчёт сохранён в локальной игнорируемой резервной копии.

## Результат

Один выбранный учебный материал прошёл путь «ручной импорт → нормализованное сообщение → SQLite-событие → решение Hermes о чтениях → результаты инструментов → карточка методики → черновик → SQLite-журнал». Hermes вернул 7 правил с привязкой к абзацам. Код проверил дословное присутствие доказательств в источнике; смысл и ограничения проверялись отдельно. Проверка совпадения цитат сама по себе не доказывает правильную интерпретацию.

Это исследовательская карточка, а не торговый сигнал. Текущая цена, entry/SL/TP и торговая зона не вычислялись. Исходный материал и изображения в репозиторий не включены.

## Управляющая роль и инструменты

Hermes сначала получил событие и описания операций, без заранее подготовленных результатов. Он выбрал `read_lesson` и `read_method_card`. Windows выполнил только эти два разрешённых чтения, вернул текст с ID абзацев и контрольными хешами, после чего Hermes подготовил результат.

Qwen, Bybit, Whisper и chart для выбранного текстового результата были отложены. Это JSON-команды ограниченного адаптера с allowlist из двух чтений, а не нативные инструменты проекта на VPS. Умение вызвать другие инструменты этим циклом не доказано.

## Ошибка и проверенное продолжение

Первый CLI-запуск попытался вызвать нативный `tool_search`, достиг лимита и завершился с кодом 1 после дополнительного summary-запроса. Событие перешло в `NEEDS_REVIEW`; автоматического повторения не было. Исправление сохранения stdout/stderr до исключения покрыто тестом.

План был восстановлен из одной известной локально проверенной сессии и прошёл проверку event key и allowlist. Заключительный ход использовал отдельный `hermes_lesson_transport.ps1` с `--toolsets no_mcp`, продолжением сессии и `--no-restore-cwd`. Перед inference проверено отсутствие доступных нативных инструментов. Заключительный ответ завершился с кодом 0, прошёл валидацию, событие стало `COMPLETED`. Это ручное проверенное продолжение после аудита, а не прозрачный retry.

Основные запросы: 10 551 входной токен, включая 2560 cache-read, и 2101 выходной. Токены summary и заголовка отдельно не установлены; точная общая стоимость и доля квоты неизвестны. Ограничение числа CLI invocations не является строгим бюджетом всех inference, auxiliary-запросов и повторов.

## Медиа

Авторские изображения не отправлялись Qwen; точные графические уровни остались неизвестными. Локальная Ollama при проверке была недоступна. Путь «авторское фото → Qwen → Hermes → Bybit» не доказан.

Отдельно проверены две локальные русские транскрипции одного разрешённого 45-секундного фрагмента: `large-v3-turbo` и `medium`, CUDA `int8_float16`, beam 3. Время транскрипции: 4,02 и 9,06 с; наблюдалось до 1241 MiB общей GPU-памяти при секундном опросе. Проверенного эталона нет, WER не рассчитывался; терминология и числа требуют ручной проверки. Исходные медиа, транскрипты и веса моделей исключены из Git. Эти транскрипты не использованы в карточке.

## Проверки и состояние

На завершении этапа прошли 72 теста, включая 9 браузерных контрактных проверок на синтетическом DOM. Тесты покрывают allowlist, неверное событие, неизвестный исход, бюджет CLI, stdout/stderr, цитаты, отказ от нативного tool use и дедупликацию завершённого события. Это не испытание Telegram 24/7.

Существующий торговый дневник не изменён. Учебный результат хранится отдельно в `events.result` на схеме `CollectorStore`; фиктивной торговой записи не создано. VPS, Gateway, OAuth, действующие боты и расписания не перенастраивались. Массовый архив и следующий этап не начинались.

Оставшиеся задачи: надёжное получение конкретного события без ручного импорта, полный учёт inference, версии бот-каталога и проверка авторских изображений после восстановления Qwen. Эти пути не объявляются завершёнными.
