# Решения владельца

Память чатов на другой ноутбук не переносится, поэтому всё важное записано здесь. Подробности этапов лежат в [плане](plan.md).

## Что делает бот

- Личный бот для одного владельца. Не торгует и ничего не публикует.
- Первая версия читала только текст. Проверка на 52 реальных постах показала, что сигналов со стопом в тексте нет: суть лежит на графиках, в видео и в обзорах. Поэтому главный объект это **зона автора**, а первая задача это разбор графиков.
- Единица данных: монета, направление, диапазон, стоп, цели. Авторы обычно дают диапазон, а не точку.

## Источники

- Turtle Way, Крипто Илья (канал и бот с уроками), Мысли Вайкоффа.
- Обучение идёт по всем постам, а не только по урокам.
- Приоритет форматов: графики на картинках, видео в Telegram, YouTube, голосовые.
- Исключение: Крипто Илья показывает позиции почти только в YouTube, поэтому его ролики идут сразу после живого потока зон. Без них он почти не участвует в совпадениях.
- История на старте: 3 месяца.

## Зоны и совпадения

- Присылать каждую зону, даже от одного автора. Совпадение двух и более авторов выделять отдельно.
- Допуск совпадения зависит от монеты и контекста. Фиксированного процента нет.
- Зона живёт, пока автор её не отменил новым постом или цена не дошла до неё и не прошла дальше.
- Нет стопа: писать «стоп не указан». Обучение предлагать стоп будет позже, вне этого плана.
- Разные мнения в одной зоне дают предупреждение.

## Веса авторов

- Стартовый вес: Turtle 1.5, Илья 1.2, Вайкофф 1.0.
- Вес показывается в сообщении и хранится в конфиге.
- Дальше вес меняется по результатам сетапов автора (этап 5 плана).

## Рынки и горизонт

- Всё на Bybit: крипта, акции, металлы.
- Горизонт: часы и дни, недели только при глобальном развороте.

## Модель

- Платный API моделей запрещён.
- Модель доступна только через Hermes по подписке ChatGPT Plus.

## Репозиторий

- Репозиторий остаётся публичным как портфолио. Историю разработки не чистить: она показывает весь процесс.
- Согласие авторов не означает разрешения публиковать их контент.
- Пуш в GitHub после каждого этапа и каждой значимой точки внутри него, чтобы на другом ноутбуке можно было продолжить с того же места.
- В `main` владелец вливает сам через PR.

## Вне плана

Свой сканер рынка, предложение стопа агентом, публикация в канал и автоторговля.
