# Состав публичного репозитория

В Git сохраняются исходники Watcher, ограниченные адаптеры Hermes, Bybit-инструменты, Qwen/Whisper-пробники, графические генераторы, SQLite-схемы и их код инициализации/обновления, тесты, зависимости, архитектурные инструкции и очищенные отчёты завершённых этапов.

Рабочая конфигурация `config/collector.sources.json` исключена; используйте `config/collector.sources.example.json` для новой установки. На существующей машине рабочий файл не заменяется. SSH-настройки Hermes загружаются из отдельного локального файла соседнего проекта и не включены в эту публикацию.

Исключены `.env`, credentials, ключи, токены, Telegram-сессии, браузерные профили, cookies/storage state, реальные SQLite-базы, исходные сообщения и медиа, конфиденциальные логи, резервные копии, виртуальные окружения, кеши, большие аудио/видео и веса моделей. Каталоги `artifacts/`, `private/` и runtime вне проекта не публикуются.

В документации удалены приватные инвайты, реальные peer/message ID, идентификаторы сессий, хеши рабочих данных, пользовательские пути и содержательные результаты по частным материалам. Три отчёта о навигации и аналитическом цикле заменены техническими публичными редакциями. Полные исходные версии изменённых документов и тестов сохранены локально в игнорируемом `private/github-publication/originals/`; они не являются частью репозитория.

Тесты используют синтетические идентификаторы и безопасный пример конфигурации. Браузерные контрактные проверки работают на локальном синтетическом DOM, не входят в Telegram и не обращаются к действующим профилям. Запуск тестов не вызывает Hermes, реальные торговые операции или публикации.

Вспомогательный Whisper worker перенесён из локальных результатов в `scripts/whisper_compare.py`; результаты по-прежнему пишутся только в игнорируемый `artifacts/`. Одноразовое проверенное продолжение Hermes сохранено как архивный шаблон `scripts/examples/resume-reviewed.py.example` с placeholders вместо локального session ID и каталога. Итог сравнения моделей — в [публичном отчёте](whisper-comparison.md); транскрипты и исходный материал остаются приватными.

Пути к `artifacts/` в исторических отчётах описывают локальные результаты; сами эти материалы намеренно отсутствуют в Git. Исторические показатели относятся к соответствующему этапу, а не являются обещанием текущей доступности сервисов или качества моделей.
