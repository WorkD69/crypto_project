# Обязательные границы Crypto Research Platform

Зафиксировано владельцем проекта 16.10.2026; относится и к будущим этапам.

1. Hermes остаётся универсальным персональным помощником. Его глобальные инструкции, память, Cron, личные сценарии, навыки, почта, уведомления и модельная маршрутизация не становятся криптовалютными.
2. Криптопроект хранит собственные материалы, знания, состояния, очереди, курсоры, историю и SQLite-базы. Личная информация Hermes, включая почту, не попадает в память криптопроекта.
3. Hermes — общий управляющий агент для криптопроекта и личных задач. Лёгкий Telegram Watcher на Windows обнаруживает изменения без LLM; предметные вызовы Hermes/Luna ограничены отдельным бюджетом криптопроекта. На этапе 0 выполнен один помеченный собственный тест через установленный Hermes CLI, без изменения его конфигурации. Исчерпание бюджета криптопроекта не отключает прочие функции Hermes.
4. Бот дяди, игровые боты, конфигурация и контейнеры Hermes, VPS-сервисы не изменяются этим этапом. Отдельные личные расписания остаются независимыми.
5. Нет торговых ключей, реальных заявок, платных API без отдельного разрешения или открытых публичных портов. Публикатор и автоматическая публикация относятся к последующим отдельно включаемым этапам.
6. Разрешения трёх авторов принимаются как установленное входное условие. Применимость способа доступа Telegram проверяется отдельно; браузерный профиль принадлежит только этому проекту, сессии других приложений не копируются.
7. Ноутбук не является источником гарантированного 24/7. При его отсутствии будущие VPS-компоненты продолжают только ранее подтверждённые функции с проверкой свежести; новые Telegram-материалы ждут возобновления локального коллектора.
8. Публичный Bybit V5, численные правила и статистика остаются детерминированными. Qwen/Whisper/Hermes не подтверждают точные цены собственным предположением. Закрытый Turtle Filter не восстанавливается.
