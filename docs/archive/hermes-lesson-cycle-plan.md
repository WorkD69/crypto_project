# План ограниченного цикла учебного материала, 18.10.2026

> Публичная редакция: локальные идентификаторы и приватные сведения удалены; исходный отчёт хранится только локально.

Утверждённая владельцем архитектура сохраняется. Один явно выбранный урок из открытого меню `CRYPTOILLIA_bot`; ручной импорт ответа `LOCAL_MESSAGE_ID` через существующий `CollectorStore`, отдельный SQLite-журнал эксперимента. Без нового сервиса, расписания и правок Hermes.

1. Проверить источник в UI и сохранить два ответа меню; полный архив уроков не загружать.
2. Добавить `tests/test_hermes_lesson_cycle.py`: отказ от неизвестного инструмента, неверного event_key, выдуманного доказательства, третьего вызова; повтор завершённого события не обращается к модели.
3. Реализовать `scripts/hermes_lesson_cycle.py`. Переиспользовать `event_payload`, транзакционную очередь, `transition` и неизменённый SSH/CLI transport. Максимум два заранее резервируемых вызова; неизвестный исход требует ручной проверки.
4. Первый ответ Hermes — JSON-запрос разрешённых инструментов `read_lesson` / `read_method_card` с аргументами. Только после его валидации выполняются запрошенные операции. Инструменты получают один фиксированный URL / один фиксированный файл, без произвольных команд и путей. Второй ответ — карточка с точными цитатами и ID абзацев. Нативные вызовы Hermes запрещены в этом эксперименте и считаются отдельно.
5. Проверить ссылки/цитаты кодом, смысл и категории вручную. Сохранить карточку, черновик, запросы/ответы и SQLite result. Не создавать торговую идею из учебного материала.
6. После текста проверить GPU/CUDA/cuDNN без загрузки моделей. При недостающих библиотеках описать минимальные зависимости; не устанавливать их без дальнейшего решения. Обновить русские отчёты и остановиться.

Проверка: `python -m unittest discover -s tests -p 'test_hermes_lesson_cycle.py'`, затем существующий набор. Превышение размера CLI-входа останавливает запрос до его резервирования.

Фактическая корректировка после проверки установленного Hermes: первая CLI-попытка потребовала аудита, без автоматического повторного запроса. Состоялось одно проверенное продолжение той же сессии с нулём нативных инструментов. Начальное ограничение «2 вызова Luna» было ошибочно реализовано как 2 процесса CLI; Hermes дополнительно выполнил summary и автозаголовок. Итог — 4 логических запроса, а полные служебные токены не измерены. Все ограничения и результаты — в `hermes-first-analytical-cycle-report.md`. До строгого учёта всех inference этот адаптер не является автоматизацией с жёстким лимитом Luna.
