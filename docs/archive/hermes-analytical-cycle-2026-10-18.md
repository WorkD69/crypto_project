# Проверка источников и подготовка аналитического цикла — 18.10.2026

Публичная редакция технического отчёта. Инвайты, peer/message ID, снимки авторизованного интерфейса, контакты, исходные ответы ботов и сведения OAuth оставлены только в локальной резервной копии.

## Результат проверки

Для одного разрешённого источника проверена цепочка «исходный инвайт → OPEN IN WEB → завершение загрузки → профиль канала». Одного совпадения заголовка недостаточно. Конкретная привязка находится в игнорируемом `config/collector.sources.json`; источник остаётся выключенным. Вступление и массовый сбор не запускались.

Образовательный бот проверен отдельно от канала. Карта различает корневое меню, разделы, карточки материалов и внешние ресурсы. Точные ответы, маршруты и адреса, полученные из авторизованного диалога, не публикуются. Доступ из отдельного Playwright-профиля Watcher в этой итерации не перепроверялся.

## Граница существующего transport

`scripts/collector/handoff.py` принимает только собственный тестовый текст `saved` с маркером `CRP-STAGE0 HERMES-FIRST`, без медиа. Тестовый prompt требует `NO_ACTION`. Этот путь проверяет доставку события, но не подтверждает управляющий анализ авторских материалов.

Для отдельного учебного эксперимента подготовлен ограниченный JSON-адаптер: Hermes получает событие и описания операций, выбирает чтения, Windows проверяет allowlist и выполняет только разрешённые операции. Результаты возвращаются Hermes для следующего решения. Это не нативный проектный MCP на VPS.

## Сохранённая архитектура

- Windows: Telegram UI, нормализация, SQLite-событие, локальные файлы и выполнение разрешённых операций.
- Hermes: выбор дальнейшего чтения и составление результата на основании возвращённых данных.
- SQLite: версии, происхождение, резервирование вызова и состояния очереди.
- Неизвестный исход SSH: `NEEDS_REVIEW`, без автоматического повтора.

Приватные доказательства находятся в игнорируемом `artifacts/`. В Git сохраняются код, тесты и этот отчёт о техническом результате. Завершение эксперимента описано в [итоговом отчёте](hermes-first-analytical-cycle-report.md), структура навигации — в [карте адаптера](../crypto-illia-bot-map.md).

Настройки VPS, Gateway, OAuth, расписания и действующие боты не менялись.
