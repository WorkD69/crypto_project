# Риски и блокеры

| Уровень | Риск | Нужное решение |
| --- | --- | --- |
| Блокер | Условия [Telegram API](https://core.telegram.org/api/terms) и [Content Licensing](https://telegram.org/tos/content-licensing) ограничивают использование контента для AI. Доступ к чужому каналу не даёт разрешения. | Выбрать собственные/лицензированные источники и проверить узкое согласие для каждого автора/участника/контента до ingest. |
| Блокер испытания | Telegram Web во втором аккаунте реально открыт и читается из Codex, но MTProto всё ещё не авторизован; download тестового видео из браузера не прошёл. Live updates, альбомы, кнопки и бот не проверены. | Для коротких разрешённых материалов применять ручную передачу; для дальнейшего collector отдельно решить легальный источник и безопасную авторизацию. Не передавать сессию Hermes. |
| Высокий | Авторские определения Fibonacci extension, liquidity sweep, FVG и подтверждений ещё не формализованы. Библиотечный SMC может иметь look-ahead bias. | После разрешённого изучения уроков записать версионированные правила, тесты на только закрытых свечах и независимую проверку событий. |
| Высокий | По Bybit HTTP 200 может содержать `retCode=10006`; региональная доступность и условия меняются. | Проверять `retCode`, соблюдать лимиты, backoff, не обходить региональные ограничения. Остановить выдачу сигнала при ошибке. |
| Высокий | Рынок меняется во время очереди/LLM анализа; текущая свеча незакрыта. | TTL, повторный запрос цены и закрытых свечей, статус инструмента, отказ от устаревшего результата. |
| Средний | 2 GB VPS уже занят Hermes и другим сервисом; 5.3 GB свободного SSD. | Только малые процессы/SQLite, метрики памяти/диска, ограниченные кэши, тяжёлое на ноутбуке. |
| Средний | Image CLI путь Hermes работает, но Telegram media ingestion и отдельный vision-tool не проверены; один читаемый график не показывает надёжность. | В следующем этапе тестировать собственные Telegram-вложения и набор графиков с разным размером/подписями, измерить ошибки. |
| Средний | Урок Telegraph публично читается, но права на переработку/хранение не установлены. | Получить разрешение правообладателя, хранить минимальные метаданные до этого. |
| Средний | Локальная Qwen и браузер зависят от ноутбука; Plus квотируется. | Учебная очередь с ожиданием, рыночная очередь с TTL; явный бюджет и ручной fallback. |
| Средний | Любой текст Telegram/Telegraph может быть prompt injection для Hermes. | Разделить collector и агент, помечать источник как данные, не выдавать секреты/инструменты через content, журналировать происхождение выводов. |

Перед Codex Plan Mode нужно принять: допустимые источники и текст согласия; границу между collector и Hermes; точные правила автора и критерии валидации; формат сценария и политика публикации; SLA/TTL по таймфреймам; лимит Plus; механизм удаления/отзыва данных; место хранения сессии и резервные копии.
