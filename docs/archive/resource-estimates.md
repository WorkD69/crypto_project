## Размещение

**VPS постоянно:** только лёгкий планировщик/получатель разрешённых событий, маленькая SQLite БД, кэш метаданных источников и свечей, контроль rate limit, TTL и повторная проверка цены. Даже это требует резервирования RAM/диска для уже работающих Hermes и игрового сервиса; не запускать тяжёлый браузер, Whisper, Freqtrade, TradingAgents или локальную мультимодальную модель.

**Ноутбук по требованию:** Ollama/Qwen, визуальная проверка, рендер сложных графиков, ffmpeg, Whisper и видео. Ноутбук может быть выключен; никакой критичный рыночный сигнал не должен ждать его пробуждения. Hermes browser тоже зависит от ноутбука.

## Две очереди

1. **Учебная:** источник и разрешение, hash документа, размер, дата, версия извлечения, статус, попытки, идемпотентный ключ. Может ждать часы/дни; при недоступной Qwen остаётся queued, без автоматического расхода Plus. После отзыва согласия прекратить обработку и удалить рабочие копии согласно политике.
2. **Рыночная:** `symbol`, `timeframe`, закрытая свеча, `created_at`, `expires_at`, снимок цены, правило и источник факторов. TTL задаётся по горизонту сигнала, при просрочке — discard/recompute. Перед показом сценария заново получить цену, instrument tick size, статус контракта и последние закрытые свечи; при недоступном Bybit не выпускать старый сигнал. Дубликаты по `(symbol,timeframe,candle_start,rule_version)`.

## Вызовы и стоимость: оценки, не замеры

- Один текстовый документ: 0 LLM для HTTP/структурного извлечения, затем обычно 1 короткий локальный или Luna вызов для классификации/фактов; дополнительный 1 для человеческой проверки может понадобиться по сложности. Telegram-материалы требуют разрешения до такого шага.
- Один скриншот: 1 vision-вызов плюс 0–1 проверка против свечей; полный Hermes CLI контекст в замере занял 11,767 input tokens. Квота Plus тратится на Luna/Sol и вспомогательные title/review/compression вызовы.
- Одно короткое видео: 0 Plus для ffmpeg+локального Whisper; если анализировать 2–4 ключевых кадра через Luna, оценка 2–4 image вызова или один пакетный вызов, плюс 1 текстовый синтез. Фактическое потребление для видео через Hermes не измерено.

Глобальные лимиты Plus не фиксированы и зависят от текущего аккаунта; не переводить количество вызовов в деньги или гарантированный throughput без реального будущего замера. Фоновые review/сжатие Hermes тоже расходуют квоту. Ограничивать LLM бюджет на документ/кадр и не запускать нагрузочный тест ради оценки.
