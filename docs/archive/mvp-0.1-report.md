## Тестовое правило и граница вывода

`scripts/mvp_scenario.py` использует **только закрытые свечи**. На снимке явно записаны индексы и timestamps минимума и максимума из первых 48 свечей окна 56; тестовая ценовая область берётся из самой широкой свечи следующих восьми **без обращения к Fibonacci**. Область должна возникнуть после обеих опорных свечей. Направление определяется порядком опорных точек, зона Fibonacci 0.5–0.618 — простая демонстрационная формула. Пересечение само по себе не даёт вход: требуются корректный порядок entry/SL/TP, R:R ≥ 1.5 и близость последней закрытой цены. Уровни кандидата округляются по tick size. Этот тест не является liquidity sweep, FVG, авторским Fibonacci или торговой стратегией; нет бэктеста и оценки вероятности успеха.

## Воспроизведение

```powershell
python -m unittest discover -s tests -p 'test_mvp_scenario.py'
python scripts/run_mvp.py
python scripts/video_probe.py
python scripts/local_content_probe.py --image C:\path\to\permitted-chart.jpg
```

`local_content_probe.py --text-stdin` читает разрешённый текст из stdin, не сохраняет его и обращается только к локальному `127.0.0.1:11434`. `video_probe.py` по умолчанию использует собственный `artifacts/test_video.mp4` и установленную tiny.en-модель без новых загрузок. `run_mvp.py` делает только два публичных GET-запроса Bybit и не создаёт ордеров. `artifacts/` игнорируется Git; чужие уроки и Telegram-сессия туда не переносились.

## Ресурсы и следующие препятствия

В этой итерации: **0 вызовов Luna/Sol и 0 расхода Plus**, 3 вызова локальной Qwen для Telegram-теста, 0 LLM-вызовов для Bybit/графика/видео. Предыдущий отдельный Hermes vision spike затратил 1 основной вызов Luna и вспомогательное создание заголовка; это не повторялось. Для надёжного видео из Telegram нужен разрешённый способ получать локальный файл без копирования браузерной сессии; Web UI не заменяет постоянный collector. Для русского видео нужна проверка multilingual Whisper на разрешённом коротком оригинале. Для авторских правил нужны определения, права и контрольные примеры. Для публикации нужен новый снимок рынка и отдельное подтверждение конкретного поста.
